# 临时活动用电送电许可工作台

本项目为展会、演出和临时施工现场提供可追溯的临时用电办理工作台。申请人建立活动档案，方案工程师登记回路并完成容量与保护核算，现场检查员记录完整检查清单和整改项，责任人提交证据并接受复检，审批负责人复核后冻结方案并签发带 SHA-256 校验摘要的不可变送电许可。

服务由 Go 标准库实现，浏览器页面和同源 JSON API 由同一进程提供。业务数据保存在本地 JSON Lines 事件日志与原子投影快照中；每条事件包含序号、前序摘要和本条摘要，启动时会校验快照并重放后续事件。

## 构建

```bash
go build ./cmd/powerpermit
```

## 运行

```bash
go run ./cmd/powerpermit -addr=127.0.0.1:19081
```

浏览器访问 `http://127.0.0.1:19081`。默认监听地址为 `127.0.0.1:19081`，不会绑定外部网络接口。可通过 `-addr=127.0.0.1:<port>` 指定监听地址，也可设置 `PORT` 为端口号；未显式修改 `-addr` 时，服务会绑定 `127.0.0.1:<PORT>`。

默认数据目录为 `data`，可使用 `-data=<path>` 指定。目录内的 `events.jsonl` 是追加式事件日志，`snapshot.json` 是可原子替换的查询投影。生产使用时应限制该目录的访问权限并纳入备份。

## 自检

以下命令在临时数据目录启动真实 HTTP 服务，通过同源 API 执行建档、方案核算、完整现场检查、安全复核、冻结与许可签发，并验证许可摘要。自检有时间边界，完成后主动关闭服务和清理临时数据。

```bash
go run ./cmd/powerpermit -addr=127.0.0.1:19081 -selfcheck
```

## 测试

```bash
go test ./...
```

测试覆盖负荷与保护参数核算、状态机、检查清单、整改责任人权限、复检关闭、乐观并发、幂等请求、事件链、重启恢复和 HTTP 输入校验。

## 接口约定

所有状态变更请求均使用 JSON，并包含 `actor`、`idempotencyKey` 和 `expectedVersion`。客户端应从最新案件投影读取 `version` 作为下一条命令的 `expectedVersion`；版本过期时 API 返回 `409 VERSION_CONFLICT`。相同 `idempotencyKey` 不会重复执行命令。

主要入口包括 `GET /`、`GET/POST /api/cases`、方案与检查子资源、整改证据、复核、许可查询、许可打印页以及按案件读取的持久审计时间线。许可打印页为 `GET /permits/{caseID}/print`。
